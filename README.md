# 🌳 MoneyTree

เว็บบันทึกการเงินส่วนตัว (ผู้ใช้คนเดียว: `Jasdakorn`)

- **Frontend:** React + Vite + TypeScript + Tailwind → Vercel (deploy อัตโนมัติเมื่อ push `main`)
- **Backend:** Supabase (Postgres + Auth + Storage), project `moneytree` (`msbtkehdocssafixbljv`, Singapore)

## ฟีเจอร์

| หน้า | ทำอะไร |
|---|---|
| ภาพรวม | สรุปรายรับ/รายจ่ายเดือนนี้, รายการประจำที่ถึงกำหนด, รายจ่ายตามหมวด |
| อัปโหลดสลิป | เลือกสลิปหลายรูปพร้อมกัน → อ่าน QR + OCR (ไทย/อังกฤษ) → เติมจำนวนเงิน/วันที่/เวลา → แมปผู้รับอัตโนมัติ, กันสลิปซ้ำด้วยเลขอ้างอิงใน QR |
| รายวัน | ปฏิทินรายเดือนพร้อมยอดรับ/จ่ายแต่ละวัน, ดูรายการ/รูปสลิปของแต่ละวัน, กรองรายรับ/รายจ่าย/สลิป |
| รายการประจำ | รายรับ/รายจ่ายประจำ (ทุก N สัปดาห์/เดือน/ปี เช่น ค่าน้ำทุก 3 เดือน) กด "บันทึก" หรือ "ข้าม" เมื่อถึงกำหนด |
| ผู้รับ/แมป | แก้ชื่อ/ประเภท/หมวดของผู้รับ, ดูและลบกฎการแมป, เพิ่มคำค้น |

### การแมปสลิปทำงานอย่างไร

QR บนสลิปธนาคารไทย (mini-QR สำหรับตรวจสอบสลิป) มีแค่ **รหัสธนาคาร + เลขอ้างอิงรายการ** ซึ่งไม่ซ้ำกันทุกครั้ง
จึงใช้กันบันทึกซ้ำได้ แต่ระบุร้านไม่ได้ ระบบจึงจับคู่ผู้รับด้วย 2 วิธี:

1. **PromptPay / Thai QR ของร้าน** — ถ้ารูปมี QR รับเงินของร้าน (tag 29/30) จะจำเลข PromptPay/Biller ID ไว้ (แม่นยำ 100%)
2. **ข้อความบนสลิป (OCR)** — ครั้งแรกกรอกชื่อผู้รับเองและเลือกบรรทัดชื่อผู้รับบนสลิปเป็น "คำค้น"
   ครั้งต่อไปสลิปที่มีข้อความนี้จะเด้งว่าแมปเข้าผู้รับนั้นให้เลย

OCR ทำงานในเบราว์เซอร์ (tesseract.js) — ครั้งแรกจะโหลดไฟล์ภาษาไทยประมาณไม่กี่ MB แล้ว cache ไว้

## Development

```bash
cp .env.example .env.local
npm install
npm run dev
```

`npm test` — unit tests (parser QR/OCR/matching) · `npm run build` — typecheck + build

## Database

Migration อยู่ใน `supabase/migrations/` (apply แล้วบนโปรเจกต์ moneytree)
ทุกตารางเปิด RLS: เข้าถึงได้เฉพาะแถวของผู้ใช้ที่ล็อกอิน · รูปสลิปเก็บใน bucket `slips` แบบ private (ดูผ่าน signed URL)

## Login

หน้า Login ล็อกชื่อผู้ใช้ไว้ที่ `Jasdakorn` ตรวจรหัสผ่านผ่าน Supabase Auth
(บัญชีจริงคือ email ใน `VITE_OWNER_EMAIL`) — รหัสผ่านไม่ได้อยู่ในโค้ด
